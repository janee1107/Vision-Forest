# 願景之森 Vision Forest

以終為始：從想要的未來，回頭看今天。口袋之森系列的第二款。

- 線上使用：https://janee1107.github.io/Vision-Forest/
- 用 iPhone Safari 打開 → 分享 → 加入主畫面，就能像 App 一樣使用，離線也能開
- 資料只存在你自己的手機裡，不會上傳；換手機前請在「設定與備份」匯出

## 怎麼用
1. **樹冠**：寫下五年後想要的生活，最多 5 條，每條屬於一個生活面向
2. **根**：每一年最多 3 個結果（2026 暖身年 1 個），每個結果都要連回一條願景
3. **關鍵行動**：只有「今年」的結果能展開行動，每個最多 3 個（2026 為 2 個）
4. **每週六**：回答「這週，我為想要的未來做了什麼？」
5. **年底**：讀完一整年的回答，收成一圈年輪

## 更新版本
修改 `index.html` 後，把 `sw.js` 裡的 `CACHE` 版本號 +1，手機重新開啟兩次就會套用新版。
